# myapp configuration reference

This is the operator-facing configuration reference. It is intentionally
thorough. Each section documents one subsystem and the defaults it ships with.

## Timeouts

Every outbound call is bounded. The default request timeout is 60 seconds,
applied uniformly to all backends.

high-concurrency tiers.

## Retries

The client retries transient failures up to 5 times before surfacing the
final error.
